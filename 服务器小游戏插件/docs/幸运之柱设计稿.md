# 幸运之柱（LuckyPillar）设计稿 v1.0（定稿）

> 状态：**定稿，代码未开始**。实现落在新插件 `LuckyPillar/`（第 13 个，沿用 MiniGameLib + HubCore 约定）。
> 一句话：开局全员被丢到**圆形排布的哭泣黑曜石柱**顶上（空背包），每 2 秒**每人各得 1 件随机物品**（任何东西，镐子/水桶/岩浆桶/食物都在池子里）；
> **世界边境墙**从外向内缩，圈外方块被吃掉、掉下去淘汰；全程有**箭雨 / 苦力怕雨**（公屏播报，覆盖圈内全范围）；
> 缩到半径 2 时开始 **TNT 雨**（能炸方块也能伤人；中心只有柱底的 3×3 草方块平台，柱顶高度要站自己搭），最后活着的人获胜。

## 0. 决策清单（全部已确认，不再讨论）

| # | 决策 |
| --- | --- |
| 1 | 战利品**没有固定表**：每次随机给「任意 1 件物品」，镐子也在池子里；柱子不设保护，能挖就挖 |

| 6 | **不锁饥饿**，幸运物品里有食物 |

| 10 | 柱子数量 = **开局玩家数，不多不少** |

## 1. 一局的时间轴

```
等待（30s 自动倒计时） → 开局 3s（清场、按人数生成柱阵、传送、空背包） → 准备期 60s（圈不动） → 缩圈期 → 终局 TNT 雨 → 结算 8s → 回主城
                            │                                          │
                            └ 柱数 = 开局人数，柱顶同高                 ├ 边境缩到半径 2，边境冻结
                                                                        └ 天灾池换成 TNT 雨，频率随存活人数加快

 准备期：圈在「柱环 + shrink-start-gap（20 格）」处静止，先给玩家捡物品
 缩圈期：每 2s 每人 1 件随机物品（动作栏提示，不刷公屏）
        每 20~25s 从「箭雨 / 苦力怕雨」随机抽一种，公屏播报
        边境墙每 tick 收缩，圈外方块逐批消失；圈外玩家掉血
```

- 开局：清场 → 按人数生成 N 根柱（**中心柱底铺 3×3 草方块平台**）→ 全员传各自柱顶、`SURVIVAL`、血量回满、**背包清空**。
- 缩圈到半径 ≤ 2（圈内只剩约 5×5 空地，站的地方自己搭）→ 冻结边境 → 进入终局。
- 剩 1 人立即结算；终局超过 `final-max-seconds`（120 s）按剩余人数/血量排名结算。
- 结算：冠/亚/季军公屏广播，冠军 +1 写 `players.yml`，全体回主城，场地清空。

## 2. 场地（只配两个点）

| 点 | 含义 |
| --- | --- |
| `center` | 游戏中心点 = 圆心 + **柱顶高度**（中心平台铺在**柱底高度**，见 `center-platform-radius`，默认 1 = 3×3 草方块） |
| `lobby` | 等待点（玩家在此等开局，倒计时结束从这儿传送） |

- 其余全自动：**柱子、中心平台、等待点平台都不用上手搭**（中心平台默认 3×3 草方块，铺在柱底高度）。
- `lobby` 若脚下没有方块，保存时自动铺 5×5 平台。
- 世界建议 `world_lp`，**VOID（虚空）**：没有地形要还原；用 FLAT 也行，只要柱底离地 ≥ 4 格。

### 2.1 柱阵（开局按人数现生成）

```
柱数 P   = 开局人数 N            // 不多不少，2 人就是 2 根
柱间距   = 16 格（固定）
环半径 R0 = N × 16 / 2π ≈ 2.546 × N   ，clamp(5, 32)
柱子     = CRYING_OBSIDIAN，柱顶 1×1，柱顶 Y = center.y，向下 pillar-depth（默认 30）格
中心平台 = center 处、**柱底高度**（柱子最低一格）铺 (2r+1)² 草方块；默认 r=1 即 3×3
           （center-platform-radius: 0 = 不铺）
```

| 人数 N | 柱数 | 环半径 R0 | 柱间距 | 缩圈时长 45+10N |
| --- | --- | --- | --- | --- |
| 2 | 2 | 5.1 | 16 格 | 65 s |
| 4 | 4 | 10.2 | 16 格 | 85 s |
| 8 | 8 | 20.4 | 16 格 | 125 s |
| 12 | 12 | 30.6（上限 32） | 16 格 | 165 s |

> 间距固定 16 格 = 谁也跳不过去，开局几秒只能等幸运物品给方块/末影珍珠。这就是「空背包」的代价，也是前期紧张感来源。

### 2.2 场内空间

- **竖直范围**：`柱底 - 3` ～ `柱顶 + 30`（柱底 = 柱顶 − pillar-depth）。
- **水平范围**：以 center 为圆心、半径 `R0 + 4` 的方形盒。
- 这个盒子 = 事件落点范围 + 圈外方块清理范围 + 局末清场范围。
- 局末清场 = 盒内**全部方块清成 AIR**（除等待点平台）；水/岩浆蔓延出来的也一并清掉。

## 3. 缩圈（世界边境）

- 用 `WorldBorder`：`setCenter(center)`、`setDamageAmount(0)`（伤害走自己的逻辑，避免双份）、
  `setWarningDistance(4)`、`setWarningTime(10)`（贴墙红屏）。
- 开局圈半径 = **柱环半径 R0 + `shrink-start-gap`**（默认 20）：柱子大约在圈内 20 格处，开局圈不贴柱子。
- 开局后先经过 **`shrink-delay-seconds`（默认 60 s）准备期**，这段时间圈完全不动、不缩；
  之后半径从 `R0 + gap` → 2 连续收缩，用时 `45 + 10 × N` 秒（config 可覆盖）；每 tick 算 `radius`，
  每秒 `border.setSize(2 × radius, 1)` 平滑同步，竖直方向天然无限。
- **圈外方块**：水平距中心 > `radius` 的本局方块（柱阵 + 玩家搭的桥 + 岩浆/水 + 事件炸出来的）
  每 5 tick 扫一次，超界的 `setType(AIR)` + `BLOCK_CRUMBLE` 粒子 + 低频音效（中心平台不参与缩圈）。
- **圈外惩罚**：水平距 > `radius + 0.5` 且持续 3 s → 每秒 1 点侵蚀伤害。
- 淘汰主力是「脚下没方块掉下去」；边境墙只负责让玩家**看得见**圈在哪。
- 终局：`radius ≤ 2` → 冻结边境 → TNT 雨。

> 世界边境**不挡人**（原版只是墙 + 掉血），所以必须保留「圈外方块被吃掉」，否则玩家站圈外柱子上不动就能活到终局。

## 4. 局内事件（公屏播报，落点覆盖圈内全范围）

| 事件 | 间隔 | 密度 | 规则 |
| --- | --- | --- | --- |
| **幸运物品** | **2 s** | 每存活玩家各 1 件 | §5。动作栏提示物品名；背包满则静默掉脚下 |
| **箭雨** | 事件池 20~25 s | `8 + 人数` 支（上限 20） | 圈内随机位置上方 30 格落下，命中/落地后消失；公屏「🏹 箭雨来袭！」 |
| **苦力怕雨** | 事件池 20~25 s | `3 + floor(人数/3)` 只（上限 8） | 圈内随机位置上方 30 格落下，引信 40 tick、**不炸方块只伤人**；公屏「💥 苦力怕雨！」 |
| **TNT 雨（仅终局）** | 每波 1.2~3 s（按存活人数压缩） | 每波 1~2 个 | 3×3 上方落下，引信 20 tick，**既炸方块也伤人**；公屏持续提示 |

- 播报格式：随机一句（如 `&c🏹 箭雨来袭！&7 抬头看天，低头看命——箭可不认人。` / `&c💥 苦力怕雨！&7 它们不拆方块，只拆你。`），见 `LuckyPillarManager` 的 `ARROW_LINES` / `CREEPER_LINES`。
- 「天灾池」= 箭雨 / 苦力怕雨，每次随机抽一种，两者不叠加。
- 苦力怕引信：`setFuseTicks(40)` 前必须先 `setMaxFuseTicks(40)`（1.21+ 默认上限 30，超了直接抛 `IllegalArgumentException: ticks > maxFuseTicks`，实测踩过）。
- **爆炸保护铁律**：对苦力怕爆炸的 `HIGHEST` 拦截必须先判「本世界 + 本场对局」，否则会吃掉单挑的风弹（真实事故，AGENTS.md §5-5）。TNT 雨不拦（要炸方块），但也只在本世界生效。
- 事件实体全部进「本局实体集合」，结算/关服统一清理。

## 5. 幸运物品（核心随机性）

### 5.1 规则

- 每 2 秒，每个存活玩家各得 **1 件**随机物品（**没有硬性权重表**；但「纯材料」和「能放不能踩」的方块按 1:4 降权，见 §5.2；另有 30% 概率直接从武器/工具/装备子池出，见 §5.3）。
- 包含：方块、镐子/剑/斧、食物、药水、风弹、末影珍珠、**水桶/岩浆桶**、鞍、唱片…… 全看脸。
- **没有初始装备**，背包全空，前 2 秒纯看风景。
- 入包 → 动作栏 `🎁 圆石`（不刷公屏）；**背包满 → 掉脚下，不提示**。
- 抽到已有装备**不做任何转换**（可能攒 40 把石剑，这是设计的一部分）。
- 饥饿正常：吃东西会饱，饱了会饿，所以食物是有效资源。

### 5.2 物品池边界

从 `Material.values()` 筛 `isItem()`，排除三类：

1. **崩服/作弊类**：`BEDROCK`、`COMMAND_BLOCK`、`CHAIN_COMMAND_BLOCK`、`REPEATING_COMMAND_BLOCK`、
   `COMMAND_BLOCK_MINECART`、`BARRIER`、`LIGHT`、`STRUCTURE_BLOCK`、`STRUCTURE_VOID`、`JIGSAW`、
   `DEBUG_STICK`、`KNOWLEDGE_BOOK`、`FILLED_MAP`、`BUNDLE`、非物品（`AIR`/`WATER`/`LAVA`/`FIRE`）
2. **过强类**：`ELYTRA`、`BEACON`、`CONDUIT`、`TOTEM_OF_UNDYING`、`ENCHANTED_GOLDEN_APPLE`、
   `END_CRYSTAL`、`RESPAWN_ANCHOR`
3. **刷怪蛋**：全部 `*_SPAWN_EGG`

其余全保留（药水随机效果、附魔书随机附魔）。**水桶、岩浆桶明确保留**——可以用来杀人或自杀，属于玩法。

**降权（不删除）**：正常物品权重 4、低价值权重 1——

- 纯材料 / 装饰（`JUNK` 表 + 名字后缀 `RECORD_`、`DISC_FRAGMENT_`、`_DYE`、`_SEEDS`、`_BANNER_PATTERN`、`_POTTERY_SHERD`、`_SMITHING_TEMPLATE`）；
- **能放置但踩不住的方块**：`Material#isBlock() && !Material#isSolid()`（`isSolid` = 默认方块状态 `blocksMotion()`，旗帜、火把、告示牌、花、铁轨…都落在这一类）。

### 5.3 武器 / 工具 / 装备抬概率 + 低阶附魔

- 每次抽物品先掷 `loot-gear-chance`（默认 **0.3**）：命中就从「武器/工具/装备」子池**均匀**抽 1 件；没命中才走 §5.2 的权重池。
- 子池 = 名字后缀 `_SWORD`、`_PICKAXE`、`_AXE`、`_SHOVEL`、`_HOE`、`_HELMET`、`_CHESTPLATE`、`_LEGGINGS`、`_BOOTS`
  + `BOW`、`CROSSBOW`、`TRIDENT`、`SHIELD`、`FISHING_ROD`、`SHEARS`、`FLINT_AND_STEEL`、`MACE`（仍过 §5.2 的三张黑名单）。
  当前登记 72 件（启动日志会打出来）。
- 命中装备后再掷 `loot-enchant-chance`（默认 **0.35**）：挂 **1 个**随机附魔，只挑 `canEnchantItem(这件)` 的，
  等级 `1 ~ min(loot-enchant-max-level, 该附魔上限)`（默认 `loot-enchant-max-level: 1` = 只有 I 级）；
  **绑定/消失诅咒不给**（名字以 `_curse` 结尾的一律跳过）。
- 三个值都在 `plugins/LuckyPillar/config.yml` 里可调，改完重启生效（局内读的是加载时 `configure` 的值）。

## 6. 淘汰与结算

| 情形 | 处理 |
| --- | --- |
| 血量归零（箭/苦力怕/岩浆/摔落/PvP） | 淘汰：广播 → **物品掉在原地（活人可捡）** → 下一 tick 自动重生、不弹死亡界面 → `SPECTATOR` → 传中心上方旁观，一直看到本局结束 |
| `Y < 柱底 - 3` | 淘汰（10 tick 兜底任务，防卡方块里不判） |
| 掉线 | 视为淘汰，重连回主城 |
| 最后 1 人 | 冠军；冠/亚/季军公屏广播；冠军 `+1` → `games.luckypillar.firsts.<uuid>` |
| 全员同时死 | 无冠军，广播平局，场地照常清空 |

- 摔落伤害不关；饥饿不锁；关火蔓延、`mob-griefing`。
- 无队伍，人人互为敌人，不存在误伤判定；`/lp leave` = 视为淘汰。
- **死亡掉落**：`PlayerDeathEvent` 不 `keepInventory`、也不清 `getDrops()`（2026-10-19 起，旧版是清空的）。
- **淘汰后不 `HubAPI.clearGame`**：否则 HubCore 认为他"已在大厅"，同一次重生的 `PlayerRespawnEvent` 会
  `teleportToLobby` 把人拉回主城（旁观失效）。淘汰的人由局末 `finish` / `leave` / 掉线 统一清状态。
- 结算展示期（ENDING）里死亡（包括"最后一个死的人"）：**同样是旁观**，看这 8 秒结算画面，8 秒后随 `finish` 一起回主城。

## 8. 配置模板（`LuckyPillar/src/main/resources/config.yml`，与线上同步）

```yaml
min-players: 2
max-players: 12

# 柱阵（开局按人数现生成）
pillar-depth: 30           # 柱子总高（柱顶向下多少格）；改大要同步抬 center.y
pillar-spacing: 16         # 相邻柱水平间距
ring-radius: 0             # 0 = 按 人数*间距/2π 自动算；>0 = 固定
center-platform-radius: 1  # 中心平台半径（1 = 3×3 草方块，铺在柱底高度）；0 = 不铺

# 缩圈（世界边境）
shrink-start-gap: 20       # 开局圈半径 = 柱环半径 + 这个值（0 = 贴住柱子）
shrink-delay-seconds: 60   # 开局后多少秒才开始缩圈
shrink-total-seconds: 0    # 0 = 45 + 10*人数
shrink-target-radius: 2    # 缩到 2 = 圈内只剩约 5x5 空地（柱底平台留在圆心），之后冻结边境进终局
out-of-zone-damage: 1
out-of-zone-grace-seconds: 3

# 事件
loot-interval: 2
disaster-interval: 22      # 天灾池（箭雨/苦力怕雨）统一间隔
pvp: true

# 终局
final-tnt-interval: 2.5
final-max-seconds: 120
final-tnt-fuse: 20

# 场地（/lp save 写入，只有两个点）
arenas:
  天灾柱:
    world: world_lp
    center: {x: 0, y: 80, z: 0}
    lobby: {x: 0, y: 90, z: 0}
```

> YAML 冒号后必须有空格，否则整份配置加载失败（场地全没），`verify.ps1` 会检查。

## 9. 插件结构（`LuckyPillar/`，6 个类）

| 文件 | 职责 |
| --- | --- |
| `LuckyPillarPlugin.java` | onEnable/onDisable，加载 Manager，注册命令/监听，`registerGame("幸运之柱")` |
| `LuckyPillarManager.java` | 状态机、开局生成柱阵、边境收缩、天灾调度、结算、播报文案（**最常改**） |
| `LuckyPillarArena.java` | 场地字段、柱阵生成（圆周均分）、本局方块/实体集合、局末清场 |
| `LuckyPillarListener.java` | 伤害/死亡/掉线淘汰、圈外掉血、爆炸拦截（苦力怕只伤人）、掉落物归属、SetupMode 回调、PvP 开关 |
| `LuckyPillarLoot.java` | 「任意物品」随机池 + 黑名单 + 药水效果/附魔随机（纯静态） |
| `LuckyPillarCommand.java` | 命令、权限、tab 补全 |

依赖 `MiniGameLib`（HubAPI / Chat / SetupMode / WaitCountdown / PlayerStats）+ `HubCore`。

## 13. 已知风险

| 风险 | 处理 |
| --- | --- |
| 世界边境在同世界的多个场地间冲突 | 一场一个专属世界（`world_lp` 独占） |
| 边境不挡人 → 玩家站圈外磨时间 | 保留「圈外方块被吃」+ 每秒 1 点伤害 |
| 苦力怕爆炸吃掉别的小游戏的风弹（真实事故） | 拦截前先判「本世界 + 本场对局」，否则 `return` |
| 玩家卡在方块里/掉进虚空极慢 | 10 tick 兜底 `Y < 柱底-3` 即淘汰并传送 |
| 背包 2 秒一件很快满 | 掉脚下且不提示（你指定）；`loot-interval` 可调 |
| 随机到末影珍珠/风弹 → 无限位移 | 属于玩法，前期就靠这些过柱子 |
| 随机到水桶/岩浆桶 → 流体蔓延 | 清场按整盒扫 AIR，流体一并清掉；圈外流体也会被吃 |
| 随机到鞘翅/信标 | 已进过强黑名单 |
| 圈缩到半径 2 还有人没死 | `final-max-seconds` 封顶，按剩余人数/血量排名结算 |
