# MemoryFlip（记忆翻牌）—— 速查卡

> AI 先读这一段，别先读源码

- **一句话职责**：每位玩家一面**竖直翻牌墙**（默认 4×4 = 16 格，必须是偶数），墙上全是物品展示框；开始时全部显示问号地图画，玩家翻两张相同的物品即得 1 分，先翻完全部对子的人获胜；到时间没翻完按已配对数量排名，记录前三名。命令 `/memory`（别名 `/mem`、`/memoryflip`、`/flip`），显示名 `记忆翻牌`。
- **规则**：
  - 每个玩家独立一面墙，`rows × cols` 必须是偶数；物品池里的物品**成对**发到墙里，所以每种物品数量必然是偶数。**每局都会重新播种随机，物品组合和牌面位置每局都不一样；物品池种类要大于对数，组合才会明显变化。**
  - 开局所有展示框显示问号地图画；**左键或右键**点一张框 → 显示该格的物品；再点另一张不同的框 → 延迟 `review-delay-ticks`（默认 20 tick）后校对：
    - 两个物品相同 → 两个框变成 ✓ 地图画、该玩家 +1 分；
    - 不同 → 两个框变回问号。
  - **同一面框在一轮内点第二次不算**（不会触发校对）；已配对（✓）的框不能再点。
  - 先配完 `totalPairs` 对的人完成；全部玩家都完成或时间到即结算。
  - **排名**：已完成的按完成用时从短到长排在前；未完成的按已配对数从多到少，再按名字。前三名 +3/+2/+1 积分并记 `firsts/seconds/thirds`（`games.memoryflip`）。
  - 场内玩家无伤、不能破坏/放置方块、不能丢东西；展示框玩家无法拿走物品；**局内隐藏头顶名字**（防止挡住牌面）。
- **命令**：`/memory`（别名 `/mem`、`/memoryflip`、`/flip`）
  - 玩家：`join`、`leave`、`list`、`stats [玩家]`、`help`
  - OP：**`build [人数]`**（站在场地中心，生成四排相对的翻牌墙 + 地台 + 展示框，人数必须是偶数，会先清掉旧场地）、`setlobby`、`save`、`start`、`stop`、`reload`、`stats reset`
- **配置**：`server/plugins/MemoryFlip/config.yml`
  - `min-players` / `max-players` / `game-seconds`（默认 300）/ `countdown-seconds` / `review-delay-ticks`
  - `board.rows` / `board.cols`（乘积必须偶数）/ `board.spacing`（相邻墙面间距，默认 6）/ `board.wall-material` / `board.floor-material`
  - `board.items`：牌面物品池（会自动成对）
  - `lobby`（`/memory setlobby` 写）
- **建场步骤（OP）**：
  1. 找一块空地的中心站好（朝向随意），执行 `/memory build 16`（不写人数 = `max-players`）。会以你为中心生成**四排相对的翻牌墙**（北/东/南/西各一排，围成一圈，玩家站在圈内朝自己的墙），前面铺地台、站位自动算好。
  2. 站到场外执行 `/memory setlobby`。
  3. `/memory list` 应显示「已配置」和翻牌墙数量；`/memory start` 测试。
  - **人数只能是偶数**（4~32）：奇数会自动减 1 再生成；16 人时四排各 4 面。
  - **严格对称**：建场以玩家最近的**方块角**为对称中心（偶数宽的墙心都落在方块角上），墙、展示框、地台、站位在**左右镜像、前后镜像、180° 旋转**下完全一致；南/西两排此前相对站位偏 1 格的问题已修。
  - 间距若填奇数会向上取偶数；多出的两面同时加在相对的两侧（北/南）。
  - 注意：四排围成一圈，需要足够空旷的场地（默认 16 人、间距 6 时约 40×40 格）。**旧版本建的场地要重新执行 `/memory build`**（`clear` 只清它自己记录过的方块）。
- **街机派对**：已接入本局池（key `memoryflip`，命令 `memory join` / `memory start`，`max-players: 16`，非多场地）。派对会直接把人拉进来再开局。
- **常见坑**：
  - **`build` 清场**：会删掉上一次 `build` 记录的墙和展示框（只清它记录过的方块），然后重新生成；不要在已建好的建筑里执行。
  - **展示框被玩家动过**：插件会取消玩家对展示框的点击/破坏，但仍建议把场地放在无人破坏的区域。
  - **物品池不够**：需要至少 `totalPairs` 种物品，不够时会循环取用（会出现多于两件同物品，仍然能配对）。
- **验证**：
  1. `/memory list` → 已配置、墙数量正确；`/hub games` 有 **记忆翻牌**。
  2. `/memory join` 两三个人 → 开始：每人被传到自己的墙前，所有框显示问号。
  3. 左键/右键点两张不同框：相同 → 变 ✓ 并 +1；不同 → 变回问号；同一张点两次不触发。
  4. 翻完所有对子 → 播报完成用时；全部完成或时间到 → 前三名带 ★ 播报，`/memory stats` 能查到。
  5. 派对里抽到记忆翻牌 → 能正常加入、开局、回报名次。
