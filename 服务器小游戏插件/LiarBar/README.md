# LiarBar（骗子酒馆）—— 速查卡

- **一句话职责**：大厅型多桌牌局。玩家**走进 pos1~pos2 区域**就自动算进酒馆（不用 `/liarbar join`），
  **右键楼梯椅子落座**，再右键槽位 2 的**准备道具**；**四人坐满自动开**，或者两人/三人时
  **全员都准备好**也能开（可打二人局、三人局）。牌库固定 20 张：钻石 / 绿宝石 / 金锭
  各 6 张 + 万能牌（下界之星）2 张；每回合随机一种目标牌，轮流出 1~3 张并声称是目标牌，下家可以**质疑**。
  质疑后有**揭幕环节**（每人面前出现物品展示框，问号从左到右翻开），随后由该负责的人拿**铁锄头左轮**
  亲手开枪：空枪出水，中弹则头顶发射器**一格一格往下流岩浆**、缓慢烧死并留下**密室杀手同款尸体**观战。
  最后存活者获胜。多张桌子可以同时开着，互不影响。**游戏开始前不清玩家背包**，菜单道具都还在。
  另外可以在区域内**喝酒**（随机酒名 + 随机反胃），喝完的空瓶能**扔出去砸人**。
- **命令**（别名 `/lb`、`/liars`）：
  - 玩家：`/liarbar join [桌名]`（传送到等待点）、`/liarbar leave`（**只退出当前牌局/座位，
    不传送回大厅**；走出区域才离开酒馆）、`/liarbar list`、
    `/liarbar liquor`（**所有玩家可用**，领一瓶随机酒，有冷却）
  - 管理（OP 或 `liarbar.admin`）：
    - `/liarbar pos1` / `pos2`：站到房间两个对角执行；区域内**自动进入酒馆 + 禁止破坏/放置**
      （没设区域时退回等待点周围 48 格做判定）
    - `/liarbar setspawn`：酒馆等待点（`/liarbar join` 的落点）
    - `/liarbar addchair <桌名>`：**站在楼梯方块上**执行，把它登记为该桌的一把椅子；每桌 4 把
    - `/liarbar build`：**切换建场模式**——开启后切到创造模式、在房间区域内可以破坏/放置方块；
      再输一次关闭并还原原来的游戏模式
    - `/liarbar give <玩家> [数量]`：发随机酒（每次随机名字 + 随机颜色）
    - `/liarbar deltable <桌名>`、`/liarbar start <桌名>`、`/liarbar stop <桌名>`、`/liarbar reload`
- **牌库与牌面**：
  - 20 张：钻石 ×6、绿宝石 ×6、金锭 ×6、万能牌（下界之星）×2；每人每回合 5 张，刚好发完。
  - 每回合从三种普通牌里随机一个**目标牌**；**万能牌结算时算作目标牌**。
  - 手牌就是上面这几种原版物品本身；但**别人看你的手牌只是一张纸**（按玩家发送伪装装备包，
    自己看到的仍是真实牌面，目标牌提示也一并伪装）。伪装每 tick 会对附近玩家补发一次，
    **切换手持物品不会闪出真实牌面**。
- **玩法流程**：
  1. 走进酒馆区域（或 `/liarbar join`）→ 提示「你已进入骗子酒馆」，背包保持原样。
  2. **右键你想坐的那把空椅子**（楼梯方块）→ 直接坐上你点的那把；点到有人/非本桌的椅子会有提示。
     槽位 2 会拿到公共库统一的**准备道具**，tab 里也会显示 `[已准备]`。再右键自己的椅子（或潜行）= 起身。
  3. **开局条件**：坐满 4 人 → 3 秒倒计时自动开；只有 2 或 3 人时，**所有入座玩家都右键准备**
   → 3 秒倒计时开局（二人局、三人局）。期间有人起身/取消准备会取消倒计时。
  4. 手牌在槽位 0~4，槽位 6 是目标牌提示，槽位 8 是「质疑」钟。
  5. 轮到你时：**左键选牌（最多 3 张，发光）→ 右键打出**，宣称都是目标牌；或**右键钟质疑**上家。
  6. 质疑 → **揭幕**：每名玩家面前按这次出牌数量出现 1~3 个物品展示框，先显示问号，
     再从左到右揭开（目标牌尽量排在前面）；揭完展示框消失。
  7. 上家出的牌里**只要有一张不是目标牌**（万能牌算目标牌）→ 上家开枪；**全是真牌** → 质疑者开枪。
  8. 负责开枪的人拿到**铁锄头「左轮」**（槽位 7），**右键亲手扣扳机**；15 秒不开自动扣。
  9. 左轮：整桌共用**一把 6 弹巢的枪**，弹巢有固定顺序，**开局时从顺序里的随机位置开始**；每扣一次转一格，
     子弹固定在一个弹巢里，最多 6 次必响；响过之后重新上膛。**不再提示还剩几格到子弹。**
  10. **中弹**：座椅正上方的发射器（朝下）把岩浆**一格一格往下放**（`flow-ticks-per-block` 控制流速，
      只往下流、不水平蔓延），流到玩家身上后开始缓慢扣血；灼烧走真实伤害事件，**其他人能看到受击变红**。
      岩浆会一直留在座椅上方，直到下一回合开始才清除。血条见底前转旁观观战（**不会真的死亡**），
      原地留下**密室杀手同款 Mannequin 尸体**（完整玩家模型 + 死者皮肤，躺倒姿势）和粒子效果。
  11. **空枪**：发射器同样一格一格放水，几秒后自动收起。
  12. 出局者留座观战；最后存活者获胜（全服播报 + 记第一名）。
  13. 本局结束**全员自动从椅子上下来、留在房间里**，重新坐下即可开下一局；走出区域就离开酒馆。
- **座椅上方的发射器（可选但推荐）**：
  - 在每把椅子的**正上方**放一个**朝下的发射器**（`DISPENSER`，漏斗口朝下），坐下时插件会自动识别；
    识别不到时岩浆/水会直接从座椅上方往下流，效果仍在但少了发射器动画。
- **酒与空瓶**（独立配置 `liquor.yml`）：
  - `/liarbar give <玩家> [数量]` 发**随机酒**（OP）；**普通玩家**用 `/liarbar liquor` 自助领 1 瓶，
    冷却 `give-cooldown-seconds`（默认 30 秒）。
  - 酒名 = 随机前缀 + 现实酒名（如「冒泡的·伏特加」），颜色也随机；外观是普通药水，
    **不会触发任何原版药水效果**。
  - **只要在酒馆区域里**（坐着、等人、甚至对局中）右键酒就能喝：播放**原版的饮用动作**
    （举起酒瓶一口一口喝，约 1.6 秒），中途切换物品/丢出/松手会像原版一样中断。
  - 喝完在背包里留下一个**空酒瓶**，并获得一段**随机时长的反胃（Nausea）**，时长范围在
    `liquor.yml` 的 `nausea.min-seconds` / `nausea.max-seconds` 里配置（默认 4~12 秒）。
    **刚喝完的 0.7 秒内不会把瓶子顺手扔出去**，需要重新点一次右键才会投掷。
  - **走出酒馆区域会自动清掉**身上的所有酒和空酒瓶（`/liarbar leave` 也会清）。
  - **右键空酒瓶**把它扔出去：砸中**没落座**的玩家会有轻微击退 + 受击变红；
    砸中坐着的人**不会推动、也不会扣血，但同样会有受击变红**。
    投掷速度/击退/伤害都在 `liquor.yml` 的 `throw` 段。
- **配置（config.yml）**：`server/plugins/LiarBar/config.yml`
  - `settings.players-per-table`（4）、`min-players`（2）；开局倒计时固定为公共库的 3 秒
  - `hand-size`（5）、`max-play-cards`（3）
  - `turn-seconds`（30）、`round-delay-seconds`（4）、`end-delay-seconds`（5）
  - `chambers`（6）、`reveal-delay-ticks`（14）、`fire-wait-seconds`（15）
  - `burn-seconds`（6）、`burn-damage`（2.0）、`water-seconds`（3）、`flow-ticks-per-block`（6）
  - `room.*` 与 `tables.*` 由命令写入，不用手改
- **配置（liquor.yml）**：`server/plugins/LiarBar/liquor.yml`
  - `prefixes` / `names`：随机前缀与酒名列表，可任意增删
  - `give-cooldown-seconds`：`/liarbar liquor` 的冷却（默认 30 秒）
  - `nausea.min-seconds` / `max-seconds`：反胃时长范围
  - `throw.speed` / `knockback-horizontal` / `knockback-vertical` / `damage`：空瓶投掷参数

- **建场步骤**：
  1. 搭好酒馆房间：每张桌子摆 4 个**楼梯方块**当椅子（楼梯，不是半砖「台阶」），桌子 3×3。
  2. 可选：每把椅子的正上方放一个朝下的发射器（用于岩浆/水效果）。
  3. OP 站到房间两个对角：`/liarbar pos1`、`/liarbar pos2`（区域即自动进入范围）。
  4. 站到进门等待点：`/liarbar setspawn`。
  5. 逐张桌子登记：站在某把椅子上执行 `/liarbar addchair 一号桌`，同一桌换 4 个楼梯各一次；
     第二张桌子用另一个名字（如 `/liarbar addchair 二号桌`）。
  6. `/liarbar list` 检查每桌「椅子 4/4」。
  7. 主城菜单加一个入口（OP）：`/hub menu action <槽位> cmd liarbar join`，或让玩家自己走进区域。
- **注意 / 已知限制**：
  - **椅子必须是楼梯方块**（`*_stairs`）；半砖（`*_slab`，中文也叫「台阶」）不算。
  - **每桌最多 4 把椅子**；少于 4 把不会自动开局。
  - 坐姿用隐形盔甲架实现，对局中不能移动，潜行下坐骑会被拦下（要退出用 `/liarbar leave`）。
  - **对局中离座/`/hub` = 放弃本局**；出局后本体隐身观战，尸体是 Mannequin。
  - 房间区域内默认禁止破坏/放置；OP 用 `/liarbar build` 打开建场模式后可以随意改方块，再输一次关闭。
  - 入座后**只锁对局道具**（手牌、目标牌提示、质疑钟、左轮、准备道具），
    酒、空瓶、菜单道具在**快捷栏和背包里都可以自由移动**（含数字键换位、拖拽、换副手）。
  - 开局才清背包并发牌；进区域、坐着等人时背包与菜单道具保持不变（准备道具占用槽位 2，原物品会先备份）。
  - 坐满 4 人自动开局；2~3 人时**全员准备**也能开局（`min-players` 默认 2）。
  - 街机派对不接入；中央菜单的场地列表按「桌子」上报（`HubAPI.setArena`），桌名就是场地名。
- **玩家记录**：命名空间 `liarbar`，`games.liarbar.firsts.<uuid>`（每局冠军 +1），文件
  `server/plugins/MiniGameLib/players.yml`。
- **验证**：
  1. 直接走进 pos1~pos2 区域 → 提示「你已进入骗子酒馆」，背包里的菜单道具还在。
  2. 右键楼梯椅子 → 坐在你点的那把椅子上，槽位 2 出现准备道具；右键同一把椅子 → 起身。
  3. 拉出 tab 列表 → 准备道具点过后应显示 `[已准备]`，再点一次变回 `[未准备]`。
  4. 2 人分别入座并右键准备 → 3 秒倒计时后开一局 2 人牌局；3 人同理。
  5. 4 人坐满 → 3 秒倒计时 → 每人 5 张牌（钻石/绿宝石/金锭/下界之星）+ 目标牌提示 + 质疑钟。
  6. 左键选牌发光 → 右键打出 → 别人看到「X 打出 N 张牌，声称是 钻石」。
  7. 右键钟质疑 → 每人面前出现问号展示框 → 从左到右翻开 → 展示框消失。
  8. 负责开枪的人拿到铁锄头「左轮」→ 右键 → 空枪时发射器慢慢往下放水；中弹时岩浆一格一格流下来、
     缓慢掉血、血条见底前转观战并留下躺倒的玩家皮肤尸体和粒子。
  9. 最后一人获胜全服播报；5 秒后所有人自动起身留在房间里。
  10. `/liarbar build` 后，在区域内可以破坏/放置方块；再输一次恢复保护。
  11. `/liarbar give <玩家> 3` → 拿到 3 瓶随机名字/颜色的酒；普通玩家也能用 `/liarbar liquor` 领 1 瓶（有冷却）。
      在区域里右键喝 → 播放原版饮用动作，中途换手会中断；喝完留空瓶 + 随机反胃。
  12. 走出 pos1~pos2 区域 → 背包里的酒和空瓶自动消失。
  13. 拿着空瓶右键扔向没落座的玩家 → 轻微击退 + 受击变红；砸坐着的人不推动、不扣血，但也会变红。
