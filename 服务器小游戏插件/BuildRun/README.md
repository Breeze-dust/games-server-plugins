# BuildRun（你建我跑）—— 速查卡

> AI 先读这一段，能省掉读全部源码（7 个 Java 文件）

- **一句话职责**：一轮「你建我跑」：OP 先圈一块**模板场地**并设**衍生方向**，开局按玩家人数沿该方向**复制出同样数量的场地**；第一阶段（`build-seconds`，默认 180s = 3 分钟）每人在自己的场地里**创造模式**建跑酷，用快捷栏第 1 格道具右键打开菜单领一根**烈焰棒**（同一根棒子：**左键方块 = 起点、右键方块 = 终点**；工具菜单只有三件——烈焰棒 / 羊毛效果图鉴 / 完成建造）；**设点时那块方块会被刷成标志色——起点变绿色羊毛、终点变粉红色羊毛**（这两种羊毛谁都不能自己放、也拆不掉；**场地地板的最低那一层同样拆不掉**，活塞/爆炸/火烧也动不了它）。第二阶段按**加入顺序**轮流：**建造者先跑**，通过后**其他选手一起跑**（期间所有人碰撞箱关闭，旁观者/已结束者都是旁观模式；**其他选手一起跑的那一刻，终点方块上会挂一个发光轮廓**——粉红描边的方块显示实体，隔着建筑/地形也能看见，跑者在起点就知道终点在哪，这条跑完自动删掉）；碰到**场地地板**、跑出场地、或单次 30s 超时都判失败并转旁观；**终点要站在粉红色羊毛方块上满 1 秒才算通过**；**建造者没通过就直接跳过这条**（但**不立刻切旁观**：留在原地免伤、让观众再看 `fail-linger-seconds` 秒，默认 3s，再轮下一条）。**每次开跑（建造者自己跑 / 其他人一起跑）传送就位后没有「不许动」冻结——传送到起点马上就能走/跳**（2026-10-18 删掉了旧的 `run-freeze-ms` 与「就位·别动」提示，行动条只喊一次「开跑！」）。**轮到某位建造者时，所有人（含建造者本人）先旁观这条跑酷 `run-preview-seconds` 秒**（默认 3；展示期不计时、不判失败，到点才传送到起点开跑；聊天/标题/行动条只显示「X 的建筑」，没有「先看 Ns」字样）。**每种羊毛踩上去给一段特定药水效果**（漂浮/速度/缓慢/失明/跳跃…，`config.yml` 的 `wool` 段可改），**建造阶段也生效**，方便建造者自己试跑；**红色羊毛是「死亡方块」：跑的时候踩到立刻淘汰**（判失败 → 转旁观，和碰地板同一条路；**建造阶段踩到只提示、不会死**，方便拿它摆坑），**每条跑酷开跑时公屏都会喊一次**「死亡方块：红色羊毛 踩到就淘汰」；**菜单中行「羊毛效果图鉴」点进去是子菜单**（16 色羊毛一排一格，**鼠标悬停某格就看到那色羊毛的效果**；子菜单里的羊毛是展示物品，拿不走；右下角箭头回工具菜单）。**菜单中行最右「完成建造」**：起点+终点都设好后点它 → 该玩家转**旁观模式**看别人继续建（其他人照旧建）；**所有人点完（或有人退出后剩下的都点完）立刻进轮流跑**，不空等剩余建造时间。**双向计分**：跑者每通过 1 条 +1；建造者按**通过率 4 档**给分——通过 ≥3/4 → 0 分、≥1/2 → +1、≥1/4 → +2、<1/4 → +3（分母 = 建造者通过那一刻有资格跑的其他人，越难分越高）。总分最高获胜并记入 `players.yml`。**对局中（建造 + 跑步）不能打开任何容器、不能丢物品、也不能跟方块/实体交互（按钮、门、拉杆、压力板、箱子、工作台、盔甲架…全都按不动；右键只有"手里拿方块 + 点到普通方块"才放方块），场地里出现掉落物会立刻被清掉**（防止有人提前把方块/水桶/鞘翅存进箱子或丢在地上，开跑时再摸出来作弊）。
- **入口 / 主流程**：`BuildRun/src/main/java/com/buildrun/BuildRunPlugin.java#onEnable` → `BuildRunManager#load`（读 `arenas` + 战绩、40 tick 后兜底 `registerGame("你建我跑")` 并上报场地、启动 1s ticker）→ 等待 `WaitCountdown` → `#start`（建 `BuildRunPlot`、拉起 `PlotCopier` 复制 N 块场地）→ 复制完 `#beginBuild`（清背包、创造、发道具、180s 倒计时）→ 时间到 `#endBuild` → `#nextCourse` → `#startCourse`（建造者生存、其余旁观、开碰撞关闭、30s）→ 通过 `#startOthersRun`（其他人一起从起点跑）→ 一个个 `#onRunnerDone`（移动事件里判终点/地板）→ 全员结束 `#finishCourse`（算分）→ 没有下一条时 `#endGame`（排名、记第一名、所有人回主城、`PlotCopier` 把复制场地清回原样）。超时 `#handleTimeout`，建造者失败/掉线/没设点 `#skipCourse`。
- **命令**：`/br`（别名 `buildrun`）—— 玩家：`join <场名>`、`leave`、`list`、`stats [玩家]`、`help`；管理（OP 或 `br.admin`）：`create <名>`、`remove <名>`、`edit <名>`、`setup <名>`、`setup-exit`、`pos1`、`pos2`、`spawn`、`lobby`、`dir <+x|-x|+z|-z>`、`gap <格数>`、`save`、`start [场名]`、`stop [场名]`、`stats reset`。
- **建场道具**（`/br setup <场名>`，公共库 `SetupMode`）：**木棍** 左/右键=场地角1/角2（模板长方体，含地板与建造空间）、**箭** 右键=切换衍生方向、**金锄头** 右键=出生点、**纸** 右键=等待点、**绿宝石** 右键=保存、**屏障** 右键=退出。
- **配置**：`server/plugins/BuildRun/config.yml`（模板 `BuildRun/src/main/resources/config.yml`）——`min-players: 2`（只是**下限**）、**人数上限已取消**（`max-players` 这个键**不再读**，老配置写 8 也不生效，加几个人就复制几块场地）、`build-seconds: 180`（3 分钟）、`run-seconds: 30`（每条每次尝试 30s，2026-10-18 由 90 改过来）、`run-preview-seconds: 3`（每个建造者开跑前全员先旁观看这条跑酷几秒，0=关直接开跑；原来的 `run-freeze-ms` 开跑冻结已删，写了也不读）、`fail-linger-seconds: 3`（建造者没通过后留在原地让观众看几秒再转旁观+跳过，0=立刻跳过）、**`highlight-end: true`（其他选手一起跑时在终点方块上挂发光轮廓，隔墙可见；false = 不挂）**、`floor-tolerance: 1`、`copy-blocks-per-tick: 4000`、`max-volume: 100000`、`arenas.<场名>.{pos1,pos2,direction,gap,spawn,lobby}`；**羊毛效果**在 `wool` 段：`effect-seconds: 5`（每次踩上给几秒）、`refresh-ticks: 5`（每 0.25s 查一次脚下）、`end-hold-ms: 1000`（终点站满多久算通过）、**`death-blocks: [RED_WOOL]`（死亡方块：跑的时候踩到立刻淘汰；不写这个键 = 默认只有红羊毛，写 `[]` = 关掉）**、`effects.<颜色>: "效果名:等级"`（0 = I 级，多个用逗号隔开，如 `"SPEED:1,JUMP_BOOST:0"`；红色羊毛不在表里——它是死亡方块）（改完重启生效）。
- **玩家记录**：命名空间 `buildrun`，YAML 结构 `games.buildrun.firsts.<uuid>`（第一名次数）；唯一文件 `server/plugins/MiniGameLib/players.yml`；清空命令 `/br stats reset`（OP）。

- **判定细节（用户确认过的规则）**：
  - **失败** = 脚部 Y < 场地最低点 + 1 + `floor-tolerance`（默认 1 → 至少要离地板 2 格）、或跑出场地 X/Z 范围、或单次尝试超过 `run-seconds`。**碰到场地默认的地板就淘汰**，所以跑酷必须建在地板上方，别贴着底面。
  - **限时**：每条跑酷有**两次** 30s 窗口——建造者自己跑一次；建造者通过后，其他人一起跑再给 30s（`run-seconds`，2026-10-18 由 90 改成 30）。
  - **每条独立**：某条失败过的人，后面的跑酷照样能跑。
  - **建造者没通过**（碰地板/超时/掉线）→ 跳过这条，不扣分也不给其他人跑；**但不是立刻切旁观**：建造者留在失败的地方（对局中本来就免伤，掉进虚空也死不了）让观众看清那一下，`fail-linger-seconds` 秒（默认 3）后才转旁观并轮下一条。
  - **建造者开跑前先看 3 秒建筑**（`run-preview-seconds`，默认 3）：轮到某位建造者时，**所有人（含建造者本人）先切旁观模式飞到这条跑酷上方看 3 秒**（聊天「第 N 条 » X 的建筑」、标题「X 的建筑」、行动条「X 的建筑 · x.xs 后开跑」；不出现「先看 Ns」字样），到点才把建造者传送到起点直接开跑（没有冻结期）。展示期不计时、不判失败、不算进 `run-seconds`；`0` = 关掉直接开跑。实现：`BuildRunArena#previewUntil` 存截止时刻、`tickCue`（每 2 tick）到点调 `beginBuilderRun`。
  - **起点/终点**由建造者用**同一根烈焰棒**设置（菜单里点「设置起点 / 终点」领取）：**左键方块 = 起点、右键方块 = 终点**；起点取方块上表面中央（带朝向），并**把那块方块刷成绿色羊毛**；终点**把那块方块刷成粉红色羊毛**。换点（重新左键/右键同一块或别的方块）会把旧标志方块还原成原来的方块。**起点禁止设在地板那层**：点地板层（或更低）的方块会被直接拒绝并提示「先垫高：起点要比地板高至少 1 格」（判据就是下面那条失败线 `Y < 场地最低点 + 1 + floor-tolerance`，默认起点方块至少要在地板上面 1 格）；终点不受此限，可以贴地板。手持烈焰棒时**左键只会设点、不会拆方块**（要拆方块先换手拿别的物品）。
  - **通过 = 站在终点方块（粉红色羊毛）正上方连续满 1 秒**（`wool.end-hold-ms`，tick 级计时，中途离开就重新计时）；旧的「终点方块中心 1.5 格内」判定已取消。站在终点方块上时**不判「碰到地板」**，所以终点可以贴着地板放。
  - **开跑不冻结（2026-10-18 改）**：传送到起点后**马上就能走/跳**、计时也从传送那一刻起算，行动条只喊一次「开跑！」。旧的 1 秒「不许动」（`run-freeze-ms` / `BuildRunArena#freezeUntil` / `tickFreeze` / `freezeInPlace` / 「就位 · 别动」提示）已全部删掉；配置里再写 `run-freeze-ms` 也不读。
  - **绿色/粉红色羊毛禁止放置**：建造阶段在自己场地里放会被拦下（聊天提示「是起点/终点标志，不能自己放」）；**起点/终点标志方块也拆不掉**；要换点就重新设置起点/终点。起点和终点不能是同一块方块（那样一开局就通过）。
  - **地板（场地最低那一层）不能破坏**：建造阶段挖**自己场地最低那一层**（`BuildRunPlot#getFloorY()` = 圈选范围的 `pos1` 那层，也是判失败那条线的底面）会被拦下并提示「地板不能挖；想垫高就在上面放方块。」；地板下面本来就在场地范围外（`canEditBlock` 挡着），所以「挖穿地板掉下去」只可能从这一层下手。活塞推/拽、爆炸、火烧到这一层的方块也一并拦（`onPistonExtend`/`onPistonRetract` 只取消"动了地板"那一下，`onEntityExplode`/`onBlockExplode` 只把自己场地的地板从被炸列表里摘掉、不整场取消，`onBurn` 只拦地板方块，`onEntityChangeBlock` 拦末影人抱走/落沙这类非玩家方块变化——都不碰别人的世界/场地）。**只保护最低一层**：地板铺了 2~3 层的场地，上面那几层还是能挖（2026-10-18 用户确认的口径）；没有配置项，要改层数得改 `BuildRunPlot#isFloor`。
  - **屏障：既不许拆、也不许放**（2026-10-18）：创造模式默认能瞬间挖穿屏障，场地里带屏障的（模板里的隐形墙/隔墙）一挖就成洞。建造阶段在自己场地里**拆 `BARRIER`** → 取消 + 提示「屏障不能拆。」（`BuildRunListener#onBreak` → `BuildRunManager#protectBarrierBlock`，排在 `canBuildBlockNow` 之前，所以不会被"放行"那条抢掉）；**放 `BARRIER` 也取消** + 提示「这局不能放屏障。」（`onPlace` → `BuildRunManager#forbidBarrierPlace`；用户口径：「自己也不能放屏障」）。**没有例外**：拆/放两个判定共用 `isBuildingInOwnPlot`（建造阶段 + 自己那块复制体），`BuildRunPlot` 里"记自己放过的屏障"那套已删。屏障本来就炸不烂、活塞推不动、烧不着，所以只挂 `BlockBreakEvent` + `BlockPlaceEvent` 两处；建场模式（setup）和别人世界不受影响。
  - **红色羊毛 = 死亡方块（踩到就死）**：`config.yml` 的 `wool.death-blocks`（默认 `[RED_WOOL]`）。**跑的时候**（建造者自己跑 / 其他人一起跑）脚底踩到死亡方块 → 公屏「☠ X 踩到死亡方块！」+ 红字标题 + 死亡音效/粒子，然后**和碰地板走同一条路**：判失败 → 转旁观（建造者则按 `fail-linger-seconds` 多看几秒再跳过这条），计分照常（这条算没通过）。**建造阶段踩到只发行动条提示、不会死**（不然拿红羊毛当装饰就会反复自杀）。判定两处都做：`handleMove`（每个移动包，跑得快也不会漏过一格）+ `tickWoolAndEnd`（0.25s 兜底，站着不动/方块在脚下变化也能发现）。**每条跑酷开跑时公屏都会提示一次**「死亡方块：红色羊毛 踩到就淘汰」（`announceDeathBlock`，按 `death-blocks` 现拼；建造开始也喊一次）。红色羊毛**不再给力量效果**（老配置里若还写着 `RED_WOOL: "STRENGTH:0"` 会被忽略并打一行日志）；图鉴里那一格写「死亡方块」。
  - **羊毛效果**：站在某种羊毛上就持续刷新对应药水效果（离开后效果还剩 `effect-seconds` 秒）。绿色/粉红色是标志方块、**故意没配效果**；红色羊毛是死亡方块（见上一条）；表在 `config.yml` 的 `wool.effects`，默认（羊毛名用官方中文译名）：白色羊毛=跳跃提升 I、橙色羊毛=跳跃提升 II、品红色羊毛=生命恢复、淡蓝色羊毛=海豚的恩惠、黄色羊毛=速度 II、黄绿色羊毛=漂浮 I、青色羊毛=水下呼吸、蓝色羊毛=缓慢、棕色羊毛=挖掘疲劳、黑色羊毛=失明、灰色羊毛=隐身、淡灰色羊毛=发光、紫色羊毛=漂浮 II。**建造阶段同样生效**，方便建造者自己试跑；游戏内看这张表 = 菜单中行「羊毛效果图鉴」→ 点开子菜单，**16 色羊毛一排一格，鼠标悬停某格 lore 第一行就是「效果：跳跃提升 I」这种**（子菜单里是纯展示物品，拿不走；表格直接从 `wool.effects` 现读，不写死）。
  - **跑者可以右键隐藏其他玩家**：每次开跑（建造者自己跑 / 其他人一起跑）传送到起点时，快捷栏第 1 格发一个「**隐藏其他玩家**」道具（末影之眼，`hide` 道具 id）：右键 → 自己看不见其他玩家（`Player#hidePlayer(plugin, …)`，实体和名字都不渲染，减少干扰；碰撞本来已关闭）；**再右键一次 = 恢复显示**（道具名字/图标跟着变）。**这条跑完（通过 / 失败 / 超时就转旁观）自动恢复可见**；`/br leave`、掉线、整局结束、关服也会清掉。恢复时只 `showPlayer` 我们自己藏过的人，不碰别的插件（如密室杀手）藏的玩家；隐藏期间新上线的人也会被自动藏起来。**点空气、点方块都算一次（2026-10-18 修）**：客户端一次物理右键会连发 `UseItemOn` + `UseItem` 两个包，服务端去重靠 `ItemStack.isSameItemSameComponents`，而我们的道具一按就换名字/图标（组件变了）→ 去重失效 → 会再补一次 `RIGHT_CLICK_BLOCK`，表现就是"**对空气能切、对方块没反应**"（藏完立刻又被放出来，净效果为零）；现在 `toggleHide` 用 `lastHideToggle` + `HIDE_TOGGLE_DEBOUNCE_MS`（150ms）把同一次点击的第二个包并掉。另外 `hideOthers` **跳过旁观模式的人**：Paper 的 `hideEntity`/`showEntity` 对"默认不可见"的实体是反向的，硬 show 反而会把旁观者塞进跑者视野（跑的时候其他人都在旁观）。
  - **完成建造（菜单中行最右，绿宝石块）**：**起点 + 终点都设好**才能点，点完该玩家立刻转**旁观模式**（站到自己场地上方、背包清空），可以看别人继续建；**旁观者不受场地范围限制**（`handleMove` 的建造阶段 `confine` 只作用于还在建的人，`buildDone` 或已是 SPECTATOR 的直接放行，可以到处飞）其他人不受影响，照旧建到时间。**本局在册玩家全部点完**（含有人退出后剩下的都点完）→ `tickAll` 立刻调 `endBuild`，不空等剩余 `build-seconds`。状态存在 `BuildRunArena#buildDone`（`clearCourse` 清空，退出/掉线的人会被移除）；行动条对已完成的人显示「已完成建造 · 旁观中 · 剩余 Xs」。
  - **对局中不能开容器、不能丢物品、掉落物立刻清（防作弊）**：建造阶段和跑步阶段，本局玩家打开任何容器（箱子/陷阱箱/熔炉/漏斗/发射器/潜影盒/末影箱…）都会被**拦下并提示**（`BuildRunListener#onInventoryOpen` → `InventoryOpenEvent`；本插件自己的道具菜单/羊毛图鉴放行）；丢物品（Q）直接取消（`onDrop` → `forbidItemDrop`）。**场地里出现掉落物立刻清**：`ItemSpawnEvent` 一落地就取消（`isInsideActivePlot`），再加 **1s ticker 兜底扫**（`tickAll` → `sweepPlotItems`），`beginBuild` / `endBuild` 各再整场清一次（`clearPlotItems`）。**只按自己场地的 AABB 筛**（`plot.contains`）——场地世界和猜猜乐共用 `world_gtb`，绝不用 `world.getEntities()` 一把梭，别把别人的掉落物删了。口径 = **只拦"本局玩家 + 建造/跑步阶段"**，等待室和收尾不管；要临时放开就把 `forbidContainerOpen` / `forbidItemDrop` 的返回值改成 `false`（没有配置项）。
  - **对局中完全不许交互（2026-10-18 加严，用户原话「不要任何交互，按按钮开门都不行，建造的时候就禁止」）**：建造/跑步阶段，本局玩家右键方块**只有一种情况生效：手里拿的是方块 + 点到的是普通方块 → 放方块**；其它全部吞掉——按钮、拉杆、门/活板门/栅栏门、箱子/熔炉/漏斗/工作台/铁砧/唱片机、蛋糕/花盆/堆肥桶、**踩压力板**（`Action.PHYSICAL`），以及"拿非方块物品朝方块用"（水桶/打火石/骨粉/船/矿车/盔甲架/物品展示框…）；**右键实体**（盔甲架、物品展示框、村民、船…）也一并取消（`onInteractEntity`）。实现要点：`BuildRunListener#onInteract` 用 `event.setUseInteractedBlock(Event.Result.DENY)`，**不能用 `setCancelled(true)`**——同一个事件也管"放方块"，整套取消会把建造砍掉（`ServerPlayerGameMode.useItemOn` 的 DENY 分支直接 return，走不到 `ItemStack.useOn`）；"有反应的方块"用 `block.getType().asBlockType().isInteractable()`（= 方块类自己实现了 `useWithoutItem`/`useItemOn`，见 `CraftBlockType#isInteractable`；门/活板门/栅栏门/按钮/拉杆/箱子/桶/蛋糕/工作台/铁砧/唱片机/堆肥桶/床/钟都命中，石头/羊毛等普通方块不命中 → 照样能放）。本插件自己的道具（菜单指南针、起终点道具、隐藏其他玩家、开始纸、退出床）**先**由 `handleItemUse` 处理并 cancel，不受影响。口径同样是"本局玩家 + 建造/跑步阶段"，等待室/主城照常。
  - **开局和结束各清一次场内实体（只清非玩家）**：`BuildRunManager#clearFieldEntities` —— 范围 = **场地模板 + 本局每块复制体**（按各自 AABB 精确筛：模板 + 所有 plot bounds），开局在 `start` 里"复制前"跑一次（上一局留下的生物/载具/掉落物不会留在新复制出来的场地里），收尾在 `endGame` 清本局数据前再跑一次（建造阶段召出来的生物/船/盔甲架/物品展示框/掉落物全没），关服 `shutdown` 也跑一次。**只删非玩家实体**（`instanceof Player` 跳过），别人的世界/别的插件实体一概不碰（场地世界和猜猜乐共用 `world_gtb`，绝不用 `world.getEntities()` 一把梭删）。只扫已加载区块；AABB 外面的（比如飞到场地上空的生物）不归它管。**只在开局和收尾各清一次，对局中途不反复清**（掉落物另有 1s ticker 负责）。
  - **建造者计分（通过率 4 档）**：`passed*4 >= runners*3` → 0 分；`passed*2 >= runners` → +1；`passed*4 >= runners` → +2；否则 +3（全整数比较，边界含等号：正好 3/4 算"3/4 以上"→ 0 分）。`runners` = 建造者通过、其他人开跑那一刻有资格跑的人数（存 `BuildRunArena#runners`，`clearCourse` 清零）；**中途掉线的人算"没通过"，分母不缩水**（否则退一个人就能把通过率刷高）。没人在场能跑 → 该条不计分（不去白送 +3）。
- **常见坑**：
  - **模板区域永不参与建造**：所有人只在复制体里建，所以模板必须干净、且复制方向上的空间要是空的（复制会把目标区域覆盖成模板；局终按复制前记录 + 模板还原）。
  - **等待点建议放在复制区域之外**：复制/清理是分帧任务，若等待点落在复制带里，玩家可能被方块埋住。
  - **场地范围要连地板一起圈**（或至少让底面就是地板），跑者脚部离底面不足 2 格会被判失败（**站在终点粉红色羊毛上时不判地板**，所以终点贴地板没事）；**起点根本不允许设在地板层**（`setStart` 直接拒绝并提示「先垫高：起点要比地板高至少 1 格」，判据同失败线：起点方块要在场地最低点之上 `floor-tolerance` 格，默认 1 格），点地板设起点只会收到提示、不会刷羊毛也不会生效。
  - **模板里别用绿色/粉红色羊毛**：这两种颜色是起点/终点标志，建造阶段不许放、标志方块不许拆；模板自带的话会被当成"拆不掉的普通方块"。
  - **非 OP 挖不动方块 = 猜猜乐在抢**：GuessTheBuild 在 NORMAL 上无条件取消所有非 OP 的 `BlockBreakEvent`（不分世界，而 BuildRun 的场地世界就是 `world_gtb`）→ 本插件的 `onBreak` 必须留在 **HIGHEST** 并对「建造阶段 + 自己的场地」显式 `setCancelled(false)`（`canBuildBlockNow`）。改优先级前先看 `docs/已知坑.md` §2 那条。
  - 复制是**主线程分帧**（每 tick `copy-blocks-per-tick` 块），大场地会慢但不会卡死；`max-volume` 超过上限直接不让开局。
  - 关服 / `/br stop` 会把复制体清回原样（`shutdown()` 里 `restoreSilently()` 同步跑完）；**不要手动删 `server/plugins/BuildRun/config.yml` 之外的东西**。
  - 事件监听都先判断"是不是我的玩家/我的场"（碰撞队伍只加本局玩家、退出即移出；免伤/免饥饿只对场内玩家）。
  - `players.yml` 只由 `PlayerStats` 读写；本插件 `data.yml` 只用于首次迁移。
  - `config.yml` / `plugin.yml` 里 `键:` 后必须有空格（`verify.ps1` 会查）。
  - **改线上配置必须"先停服 → 再覆盖 → 再启动"**：本插件 `onDisable` 会 `saveAll()` 回写 `config.yml`（`saveAll` 里先 `reloadConfig()` 再只重写 `arenas` 段，所以手改的 `build-seconds` 等键不会再被内存旧值覆盖；但注释会被 YAML 写掉）。反过来若在服务器**运行中**覆盖配置，停服时旧值仍会写回 —— 症状就是"传了新配置，游戏里还是旧数值"。
  - **启动日志会打印实际生效时长**：`[BuildRun] 时长：建造阶段 180s，每条跑酷限时 30s（来自 config.yml）` —— 改完配置看这行就知道读到没有，不用开一局。
  - **面板上"本地 180、线上还是 120"（2026-10-18）**：`build-seconds` 就是读 `server/plugins/BuildRun/config.yml` 里那一行，**文件是 120 就是 120**。启动日志现在紧跟着还有一行自证：`配置：<绝对路径>（<字节> B，最后修改 <时间>）；build-seconds 取自 config.yml` —— 三样一对就定位：路径别是 `server/server/plugins/...`（覆盖落错层）、**最后修改时间要是刚才那次上传的**（不是 → 覆盖没落到这个文件）、值要是 `180`（是 120 → 面板上那份文件本身就是旧的）。修法只有一条：**停服 → 覆盖 `BuildRun.jar` + `server/plugins/BuildRun/config.yml` → 启动**（本插件无 reload）。
