# 超级牛马测试地图（sn_test）

本地测试用地图，位于 **`world_sn`**（GameWorlds 托管的 VOID 空世界，没有地面）。
世界和地图配置已经在本机 `server/` 下配好；上传面板服时需要把 `world/dimensions/minecraft/world_sn/`
和 `plugins/SuperNiuma/arenas.yml` 一起带过去。

## 跑道布局

坐标以方块为单位，平台顶面在 `y=64`：

| 区域 | 范围 | 说明 |
| --- | --- | --- |
| 等待/摆放平台 | x -4..4，z -22..-14，y 63 | 玩家出生与摆放机关 |
| 起点平台 | x -3..3，z -3..3，y 63 | 跑酷起点 |
| 机关跑道 1 | x -2..2，z 6..8，y 63 | 中间有 2 格空隙 |
| 机关跑道 2 | x -2..2，z 11..13，y 63 | 中间有 2 格空隙 |
| 机关跑道 3 | x -2..2，z 16..18，y 63 | 中间有 2 格空隙 |
| 终点平台 | x -2..2，z 22..26，y 63 | 到达即过关 |

- 出生点：`(0.5, 64, -18.5)`
- 起点：`(0.5, 64, 0.5)`
- 终点判定区：x -1..1，y 64..65，z 23..25
- 可建造范围：x -12..12，y 60..80，z -26..30
- 虚空判定：Y < 50 直接失败

## 重新铺跑道（控制台命令）

如果世界被清空或换机器，启动服务器后在控制台依次执行
（`world_sn` 是空世界，先 `forceload` 把区块加载出来，否则 `fill` 会报 "That position is not loaded"）：

```text
execute in minecraft:world_sn run forceload add -2 -3 2 3
execute in minecraft:world_sn run fill -4 63 -22 4 63 -14 minecraft:smooth_stone
execute in minecraft:world_sn run fill -3 63 -3 3 63 3 minecraft:smooth_stone
execute in minecraft:world_sn run fill -2 63 6 2 63 8 minecraft:stone
execute in minecraft:world_sn run fill -2 63 11 2 63 13 minecraft:stone
execute in minecraft:world_sn run fill -2 63 16 2 63 18 minecraft:stone
execute in minecraft:world_sn run fill -2 63 22 2 63 26 minecraft:smooth_stone
execute in minecraft:world_sn run forceload remove -2 -3 2 3
```

## 进服验证步骤

1. 启动本地服务器（`server/` 目录下）：
   ```bash
   ./jdk/bin/java.exe -Xms1G -Xmx2G -jar server.jar --nogui
   ```
2. 客户端连接 `localhost:25560`（`online-mode=false`，任意正版/离线名都能进）。
3. 用 OP 账号（`SharpOwO`）执行 `/sn arena info sn_test`，确认状态为「可用」。
4. 创建房间：
   ```text
   /sn create sn_test solo
   ```
   记下返回的房间号。
5. 再开一个客户端（或第二名玩家）执行：
   ```text
   /sn join <房间号>
   ```
   单人测试可把 `plugins/SuperNiuma/config.yml` 的 `room.min-players` 改为 `1` 后 `/sn reload`。
6. 房主执行 `/sn start`，依次验证：
   - **选择机关**：箱子界面散乱分布，点击后其他玩家看到「该机关已被【名字】选择」，界面无法自行关闭，20 秒后自动进入下一阶段。
   - **摆放机关**：自动飞行；半透明假方块出现；左键水平旋转、右键上下翻转、滚轮前后移动、Q 两次确认。
   - **跑酷**：冒险模式从起点出发，到终点变观察者；掉到 Y<50 或碰尖刺/箭也变观察者。
   - **记分**：观察结算分数是否正确，下一回合是否重新选择/摆放。
7. 结束测试：`/sn stop`（房主或管理员），确认机关方块被移除、玩家回到主城。

## 在主城菜单里打开

在 `server/plugins/HubCore/config.yml` 的菜单项加一条，然后 `/hub reload`：

```yaml
action: 'cmd sn menu'
```

## 注意

- `world_sn` 是 **VOID 世界**，只有上面这些平台；不要在该世界里直接放玩家以外的东西。
- `plugins/SuperNiuma/arenas.yml` 是运行时数据，上传面板服时按 AGENTS 约定 **不要** 覆盖线上已有的同名文件，
  除非你确认线上还没有这张测试图。
- 测试跑道的方块属于地图本身，不属于机关；`/sn stop` 只会移除机关，不会动跑道。
