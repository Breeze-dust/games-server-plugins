# 换电脑迁移说明（BuildBattle 开发包）

> 打包脚本：`pack-devkit.bat` / `pack-devkit.ps1`（可重复运行，每次覆盖生成同一天的 zip）。
> 本文就是这个包的使用说明书，解压后先看它。

## 0. 一句话

解压到 **`D:\BuildBattle`**，双击 `build.bat`，再双击 `server\start.bat`。
不用装 Java、不用装 Paper、不用联网下依赖。

## 1. 包里有什么

| 路径 | 内容 |
| --- | --- |
| `AGENTS.md` / `README.md` | 项目入口、目录地图、命令速查 |
| `docs\` | 开发须知、已知坑、玩家记录、改动记录、幸运之柱设计稿、本文件 |
| `backups\` | 玩家记录历史快照（`players-latest.yml` + 按时间） |
| 13 个插件目录 | 全部源码：`MiniGameLib` `HubCore` `GameWorlds` + 9 款小游戏 + `LuckyPillar`（含 `src\main\resources` 模板、`pom.xml`、各 README） |
| `build.bat` / `build.ps1` | 一键编译（`-Only`、`-Deploy`、`-OutDir`） |
| `verify.ps1` / `check-stats.ps1` | 上传前预检 / 玩家记录自检 |
| `pack-upload.ps1` / `server-backup.ps1` / `players-backup.ps1` / `server-pack-full.ps1` | 上传打包、整服快照、玩家记录备份 |
| `paper-classpath.ps1` | 编译依赖清单（现在支持回退到包内 `toolchain\`） |
| `toolchain\.m2\repository\` | 24 个编译期 jar（Paper 26.2 API + 传递依赖，约 32 MB），新电脑没有 `%USERPROFILE%\.m2` 也能编译 |
| `server\server.jar` + `start.bat` | Paper 26.2 服务端本体 |
| `server\jdk\` | Temurin JDK 25（含 `javac.exe`，约 289 MB；包内省掉了 52 MB 的 `jdk\lib\src.zip`） |
| `server\world\` | 主城世界（含 `dimensions\` 里的各小游戏世界，约 166 MB） |
| `server\plugins\` | 13 个自研 jar + `SkinsRestorer` + 各插件 `config.yml` / `data.yml` / `words.yml` / `arena-*.snap` + **玩家记录 `MiniGameLib\players.yml`** |
| `server\config\`、`server.properties`、`bukkit.yml`、`spigot.yml`、`commands.yml` | 服务端与 Paper 配置（端口 25560、`online-mode=false`） |
| `server\cache\` `server\versions\` `server\libraries\` | Paper 启动缓存（约 165 MB）——带上它们，新电脑开服不会再出现 `Downloading mojang_26.2.jar` |

总计 **1188 个文件**，解压后约 **675 MB**，zip 约 **361 MB**。

## 2. 没打包的东西（故意的）

| 没带 | 原因 |
| --- | --- |
| `.build\` | 编译临时产物（19k 文件 / 70 MB），`build.bat` 会自动重建 |
| `server\logs\`、根目录 `*.log` | 历史日志（含旧报错和 smoke 测试输出），排查用不上 |
| `server\world_backup_20260920_160034\` | 9 月的旧世界快照（18 MB），现役 `world\` 已在包里 |
| 根目录 `server-pack-*.zip`、`upload-package.zip` | 三次性的旧上传包，共约 750 MB |
| `server\usercache.json` | 玩家名→UUID 缓存，开服自动重建 |
| `world\session.lock` | 世界锁文件，新机开服自己生成 |
| `GuessTheBuild\META-INF\` | 一份重复的 paper-api jar（2.8 MB），编译用 `toolchain\` 里的 |
| `server\jdk\lib\src.zip` | JDK 自带源码包（52 MB），编译/开服都用不到 |
| `.git` | 仓库本来就没有版本控制；这个 zip 就是源码快照。想上 Git 的话到新电脑 `git init` 即可 |

## 3. 新电脑上怎么做（3 步）

1. **解压到 `D:\BuildBattle`**，让 `AGENTS.md` 直接位于 `D:\BuildBattle\AGENTS.md`（不要多套一层文件夹）。
   保持这个路径的原因：`verify.ps1` / `pack-upload.ps1` / `server-backup.ps1` 的默认参数写死了它。
2. **编译验证**（不用装 Java，`server\jdk` 自带）：
   ```powershell
   cd D:\BuildBattle
   .\build.bat -Only MiniGameLib     # 10 秒内应输出 [built] MiniGameLib
   .\build.bat -Deploy               # 全量 13 个插件，覆盖 server\plugins\*.jar
   ```
3. **开服**：
   ```bat
   D:\BuildBattle\server\start.bat
   ```
   客户端连 `localhost:25560`（`online-mode=false`，离线/正版都能进）。
   控制台应看到 13 个插件依次 `Enabling`，以及 `[MiniGameLib] player records ... players.yml`。

改完代码的日常循环：`build.bat -Only <插件> -Deploy` → 重启本服，或 `pack-upload.bat` 上传面板。

## 4. 编译依赖（.m2）说明

`build.ps1` 通过 `paper-classpath.ps1` 找依赖，按顺序查两个位置：

1. `%USERPROFILE%\.m2\repository`（老机器/装过 Maven 的机器）
2. `toolchain\.m2\repository`（本包自带的副本）

所以新电脑**不需要先跑 Maven**。如果你想把依赖装进用户目录（比如以后新开项目也复用）：

```powershell
robocopy D:\BuildBattle\toolchain\.m2\repository "$env:USERPROFILE\.m2\repository" /E /XC /XN /XO
```

升级 Paper 或加编译依赖时：改 `paper-classpath.ps1` 的 `$paperCpRel`，再把 jar 放进
`toolchain\.m2\repository\<同样的相对路径>`，然后跑一次 `pack-devkit.bat` 重新打包。

## 5. 到新电脑后的自检清单

```powershell
cd D:\BuildBattle
.\verify.ps1          # YAML 语法 + 关键配置 + jar 指纹，应全部 OK
.\check-stats.ps1     # 玩家记录：players.yml 存在且能合并写盘
.\build.bat -Only MiniGameLib
```

然后开服，进游戏验证：

- `/hub` 打开主城菜单，9 个游戏图标都在；
- 随便进一个游戏场地，`[GameWorlds] ... pvp=...` 日志正常；
- `server\plugins\MiniGameLib\players.yml` 里是旧战绩（不是空的）。

## 6. 常见问题

- **解压到了别的路径（不是 `D:\BuildBattle`）**：脚本本身用 `$PSScriptRoot`，编译/开服不受影响；
  但 `verify.ps1`、`pack-upload.ps1`、`server-backup.ps1` 的 `-ServerDir` 默认值要手动传，
  例如 `.\verify.ps1 -ServerDir "E:\BuildBattle\server"`。另外 `verify.ps1` 的临时目录写死在
  `D:\BuildBattle\.build\verify`，没有 D 盘就改那一行。
- **25560 被占用**：改 `server\server.properties` 的 `server-port`（本地测试用，不影响面板）。
- **Java 起不来**：`server\jdk\bin\java.exe -version` 应输出 `openjdk 25.0.4.1`；报缺 DLL 就装
  VC++ 2015-2022 运行库（Windows 10/11 一般自带）。
- **改线上配置的顺序**：先停服 → 再覆盖 → 再启动（`MurderMystery / SkyPit / TntRun / DuelArena /
  HotPotato / BuildRun` 会在关服时用内存回写 `config.yml`）。
- **上传面板**：先停面板服 → `pack-upload.bat` → 覆盖 → 启动；玩家记录默认不覆盖面板的。

## 7. 这个包怎么重新生成

```powershell
D:\BuildBattle\pack-devkit.bat
# 或指定输出位置
powershell -ExecutionPolicy Bypass -File pack-devkit.ps1 -OutFile E:\BuildBattle-DevKit.zip
```

脚本会先确认没有 java 进程（避免打包到写了一半的配置），刷新 `toolchain\`，再按白名单收集文件。
增删插件/文档后不用改脚本：带 `src\main\java` 的目录会被自动收进来。
