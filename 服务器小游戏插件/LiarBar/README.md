# LiarBar（骗子酒馆）—— 速查卡

- **一句话职责**：大厅型多桌牌局。玩家从主城进酒馆，**右键台阶椅子落座 = 准备**；一张桌子坐满 4 人自动倒计时开局。每人 5 张手牌，桌面每回合随机一个点数（A~6），轮流出 1~3 张牌并声称是桌面点数，下家可以**质疑**；翻开只判定上家最后打出的那几张——说谎者中枪，说真话则质疑者中枪。中枪要扣一次左轮扳机（6 弹巢、1 发子弹，转满 6 次必死），最后存活者获胜。**多张桌子可以同时开着，互不影响。**
- **命令**（别名 `/lb`、`/liars`）：
  - 玩家：`/liarbar join [桌名]`、`/liarbar leave`、`/liarbar list`
  - 管理（OP 或 `liarbar.admin`）：
    - `/liarbar pos1` / `pos2`：站到房间两个对角执行（房间内禁止破坏/放置，保护范围）
    - `/liarbar setspawn`：酒馆等待点（进酒馆的落点）
    - `/liarbar addchair <桌名>`：**站在台阶方块上**执行，把这个台阶登记为该桌的一把椅子；每桌 4 把
    - `/liarbar deltable <桌名>`、`/liarbar start <桌名>`、`/liarbar stop <桌名>`、`/liarbar reload`
- **玩法流程**：
  1. 主城菜单里点「骗子酒馆」（或 `/liarbar join`）→ 传送到酒馆等待点，背包换成一把「离开酒馆」的红床（槽位 8）。
  2. **右键任意一张空椅子的台阶方块** → 玩家坐上去并算作准备。再右键自己的椅子（或潜行下坐骑）= 起身。
  3. 同一张桌子坐满 4 人 → 3 秒倒计时 → 自动开局；有人起身会取消倒计时。
  4. 开局后每人 5 张手牌在槽位 0~4；槽位 6 是桌面牌提示；槽位 8 是「质疑」钟。
  5. 轮到你时：**左键点手牌选中（最多 3 张，选中的牌发光）→ 右键打出**，宣称它们都是桌面点数；或者**右键钟质疑**上家最后打出的牌。
  6. 质疑结算：上家最后打出的牌里**只要有一张不是桌面点数** → 上家中枪；**全是真牌** → 质疑者中枪。中枪扣一次扳机：空枪活下来，转到子弹就出局。
  7. 出局的人**留在座位观战**到本局结束；最后存活者获胜（全服播报 + 记第一名）。
  8. 本局结束后**所有人自动从椅子上下来、留在房间里**（不回大厅），想再来一局重新坐下即可；想走就右键红床或 `/liarbar leave`。
- **规则细节**：
  - 每回合开始，所有存活玩家重新发满 5 张牌，桌面点数随机换一个。
  - 只质疑「上家最后打出的那几张」，之前轮次别人出过的牌不再追责。
  - 一次质疑过后进入下一回合，**开枪的人（若活下来）先手**；如果他中枪出局，由他下家先手。
  - 每回合思考时间默认 30 秒，超时自动打出一张牌。
  - 左轮 6 个弹巢只有 1 发子弹，扣一次转一格；第 6 次扣扳机必定中弹。
- **配置**：`server/plugins/LiarBar/config.yml`
  - `settings.players-per-table`（4）、`start-countdown-seconds`（3）
  - `hand-size`（5，最大 5）、`max-play-cards`（3）
  - `turn-seconds`（30）、`round-delay-seconds`（4）、`end-delay-seconds`（5）
  - `chambers`（6，左轮弹巢数）
  - `room.*` 与 `tables.*` 由命令写入，不用手改

- **建场步骤**：
  1. 搭好酒馆房间：每张桌子摆 4 个**台阶方块**当椅子（台阶可以是任意材质/朝向），桌子之间拉开距离。
  2. OP 站到房间两个对角：`/liarbar pos1`、`/liarbar pos2`。
  3. 站到进门等待点：`/liarbar setspawn`。
  4. 逐张桌子登记：站在某把椅子上执行 `/liarbar addchair 一号桌`，同一张桌子换 4 个台阶各执行一次；第二张桌子用另一个名字（如 `/liarbar addchair 二号桌`）。
  5. `/liarbar list` 检查每桌「椅子 4/4」；没满就继续 addchair。
  6. 主城菜单加一个入口（OP）：`/hub menu action <槽位> game 骗子酒馆`，或 `cmd liarbar join`。
  7. 至少 4 个玩家 `/liarbar join` → 各自坐满一张桌子 → 自动开局。
- **注意 / 已知限制**：
  - **椅子必须是台阶方块**；登记时以「玩家脚下的方块」为准，也可以看着 5 格内的台阶。
  - **每桌最多 4 把椅子**；少于 4 把不会自动开局（`/liarbar list` 会显示椅子数）。
  - 坐姿用**隐形盔甲架**实现：玩家是骑在盔甲架上的，所以对局中无法移动，潜行下坐骑会被拦下（要退出用 `/liarbar leave`）。
  - **对局中离座 = 放弃本局**（视为出局）；`/hub` 或右键回主城道具也会走同样的退出流程。
  - 房间内（`pos1~pos2`）禁止破坏/放置方块（管理员权限除外），所有伤害/饥饿被取消。
  - 本游戏用「落座」代替等待室的准备道具，因此不发槽位 2 的准备道具；坐满即开局。
  - 街机派对不接入（大厅多桌不适合串场）；战绩只记第一名到 `players.yml` 的 `liarbar` 命名空间。
  - 中央菜单的场地列表按「桌子」上报（`HubAPI.setArena`），桌名就是场地名。
- **玩家记录**：命名空间 `liarbar`，`games.liarbar.firsts.<uuid>`（每局冠军 +1），文件 `server/plugins/MiniGameLib/players.yml`。
- **验证**：
  1. `/liarbar list` 能看到桌子、椅子数 4/4。
  2. `/liarbar join` → 出现在酒馆等待点，槽位 8 是「离开酒馆」。
  3. 右键台阶椅子 → 坐下、动作栏显示 `已入座并准备（1/4）`；右键同一把椅子 → 起身。
  4. 4 人坐满 → 3 秒倒计时 → 每人 5 张手牌 + 桌面牌提示 + 质疑钟。
  5. 左键选牌发光 → 右键打出 → 其他人看到「X 打出 N 张牌，声称是 A」；右键钟质疑 → 翻开上家最后打出的牌并结算。
  6. 中枪出局的人留在座位上观战；最后一人获胜全服播报；5 秒后所有人自动起身留在房间里。
